# optimal_control
1)We solve for minimum time optimal control input to stop an undamped harmonic oscillator(pendulum) to bring to origin,starting from any position and velocity. run car_optimal.slx to see the simulation
2)we solve for the minimum time and fuel optimal control input to stop a car on a frictionless x-axis and
finally bring to the origin, starting from any position and velocity .run harmonic_oscillatr_optimal.slx to see the simulation.
for both the problems , input is constrained between -1 and +1.
